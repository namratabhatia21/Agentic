# The rewrite method

## Why this matters

Knowing the four parts is one thing. Turning a rushed one-line request into a strong
prompt in under a minute is the habit that saves time every day.

**By the end of this lesson you can** rewrite a vague request as a four-part prompt, and
start turning your best prompts into reusable templates.

## Start from what you know

Recall the four parts: task, context, format, examples. The rewrite method walks through
them in order, as questions you ask yourself.

## The method

1. **Task**: start with one verb. "Draft", "summarize", "compare", "list".
2. **Context**: add who it's for and what they'll do with it.
3. **Format**: say the length and shape: bullets, table, email, number of words.
4. **Examples**: paste a past example if you have one; skip it if you don't.
5. **Read it as a stranger**: if a new colleague got only this text, could they do it?

## Worked example

> **Vague:** Help me with the meeting.
>
> 1. Task: *Write an agenda.*
> 2. Context: *for a 30-minute meeting with the design team to agree the launch date.*
> 3. Format: *3-4 items, each with an owner and minutes.*
> 4. Example: *Use the same layout as this agenda: [paste].*
>
> **Rewritten:** Write an agenda for a 30-minute meeting with the design team to agree the
> launch date. 3-4 items, each with an owner and minutes. Use the same layout as this
> agenda: [paste]

## From prompt to template

When you'll do a task again, replace the specifics with placeholders:

```
Write an agenda for a [length] meeting with [team] to [decision needed].
[number] items, each with an owner and minutes. Use this layout: [paste example]
```

Next time, you fill in the brackets instead of starting from scratch.

## Try it

Rewrite "Make a slide about sales" with the method. One possible answer: *"Create one
slide for Monday's leadership meeting showing Q3 sales against target by region. Use a
bar chart and one headline sentence stating the main gap."*

## Key takeaways

- Rewrite in order: task, context, format, examples, then read it as a stranger.
- A rewrite usually adds one or two sentences, not a page.
- Turn prompts you'll reuse into templates with [placeholders].
